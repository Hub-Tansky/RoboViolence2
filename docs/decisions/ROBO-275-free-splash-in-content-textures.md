# ROBO-275: The free first-run splash is a real image in content/textures, drawn at 16:9 covering the window

- Status: Accepted
- Date: 2026-11-26
- Affects: ROBO-275, `content/textures/`, `content/base-pack.tsv` (`textures/splash`), `CMakeLists.txt`, `game/src/SplashFit.h`, `game/src/ArtDownloader.cpp` (`splashFrame`), `tests/test_splash_fit.cpp`; follows [ADR ROBO-260](ROBO-260-art-pack-downloads-beside-the-gpl-game.md)

## Context
- ADR ROBO-260 shows `textures/splash` from the base pack while the art pack downloads; until now it was a generated 256 x 128 placeholder, since every base pack file was generated by `tools/gen-placeholder-content.py`.
- Owner, 2026-11-26: the splash is a new image without the protected ball faces, released under the GPL with the game (title included, floor stains kept as generated). The art pack's own splash stays under the art licence.
- `splashFrame` stretched the texture over the 800 x 600 menu units, so a 16:9 picture in a 4:3 window drew egg-shaped balls.

## Decision
- The base pack holds real images in `content/textures/` (GPL, author and tool in their `pack.tsv` row). The build copies them into `main/textures/`, as it copies `content/maps/`; the generator skips rows whose file is a PNG.
- The splash texture is 2048 x 1024 (power of two), resized from the owner's 16:9 picture. `SplashFit.h` draws it at 16:9 covering the window: a narrower window crops the sides, a wider one the top and bottom.

## Consequences
- A new real base pack image is a PNG in `content/textures/`, its row, and a `!` line in `.gitignore` (the folder stays ignored against original BV2 textures); it ships in every package (`install(DIRECTORY)` of `main/`).
- The picture's important parts must stay in the middle 75 % of its width, which a 4:3 window shows.
- Rejected: letterboxing (black bars on most screens); storing the 16:9 file as is (not a power of two, which the art pack checks require of textures).
